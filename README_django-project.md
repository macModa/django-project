## Getting Started

### Prerequisites

Make sure you have:

- Python 3 installed
- `pip`
- Git
- A virtual-environment tool such as `venv`

### 1. Clone the repository

```bash
git clone https://github.com/macModa/django-project.git
cd django-project
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the virtual environment

**Linux / macOS**

```bash
source venv/bin/activate
```

**Windows**

```powershell
venv\Scripts\activate
```

### 4. Install dependencies

If `requirements.txt` is available in the project root:

```bash
pip install -r requirements.txt
```

### 5. Run the Django development server

From the directory containing `manage.py`:

```bash
python manage.py runserver
```

Then open:

```text
http://127.0.0.1:8000/
```

> If the Django project is located inside `VM/`, first move into that directory before running the Django commands.
